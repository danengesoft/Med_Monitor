# UPEU MedMonitor

**UPEU MedMonitor** es una propuesta de sistema web para apoyar el seguimiento y la coordinación de la atención de estudiantes en un entorno universitario. Reúne información relevante para el personal autorizado y ayuda a organizar atenciones, alertas, derivaciones y traslados desde una plataforma centralizada.

> Este repositorio contiene documentación pública del proyecto. El código fuente y la configuración operativa se mantienen en un repositorio privado.

## Propósito

Facilitar el trabajo coordinado del personal de salud mediante una vista organizada de la información del estudiante y de los procesos de atención. El sistema busca mejorar la disponibilidad de información y la continuidad del seguimiento dentro del ámbito institucional para el que fue diseñado.

## Funcionalidades

- Gestión y consulta de fichas de estudiantes por personal autorizado.
- Registro y consulta de atenciones e historial clínico.
- Seguimiento de alertas y coordinación de traslados.
- Programación de citas y derivaciones a áreas de apoyo.
- Panel de seguimiento y reportes operativos.
- Administración de usuarios y permisos según roles.
- Registro de actividad asociada a los procesos del sistema.

Las funciones disponibles pueden variar según la configuración y el rol asignado. La plataforma no reemplaza el criterio profesional, la evaluación clínica ni los protocolos de emergencia de la institución.

## Usuarios previstos

El proyecto está dirigido a equipos institucionales autorizados, como personal médico, de enfermería, de emergencias y administración. El acceso a información y acciones se encuentra sujeto a permisos definidos por la institución.
